## Projects and current limits

### PolicyLens

![PolicyLens result example](assets/policylens-preview.svg)

Review CSP fallbacks and HTTP response headers in the browser. Comma-separated
policy lists are currently skipped.

[Open workbench](https://rogfog.github.io/PolicyLens/)

### FileSentinel

![FileSentinel result example](assets/filesentinel-preview.svg)

Save and compare SHA-256 directory snapshots with the Python standard library.
Content changes are covered; permissions and alternate data streams are outside
the snapshot format.

[Quick start](https://github.com/ROGFOG/FileSentinel#quick-start)

### RepoCards

![RepoCards result example](assets/repocards-preview.svg)

Download public GitHub metadata as an SVG card. Cards keep their capture time;
refreshing them requires generating a new image.

[Make a card](https://rogfog.github.io/RepoCards/)
